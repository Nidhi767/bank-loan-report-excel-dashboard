 Bank Loan Report Dashboard (Excel Project)

## Project Overview

This project is an interactive Bank Loan Analysis Dashboard built entirely in Microsoft Excel.

The dashboard provides insights into:

* Loan applications
* Funded amount
* Amount received
* Interest rates
* Debt-to-income ratio (DTI)
* Good vs Bad loans
* Loan trends and performance

---

## Business Problem

Banks need an efficient way to monitor loan performance, identify risky loans, and analyze repayment behavior.

---

## Objective

To design an interactive Excel dashboard that provides actionable insights into loan performance and customer behavior.

---

## Dashboard Pages

### 1. Summary Dashboard

Provides high-level KPIs and loan performance metrics.

### 2. Overview Dashboard

Displays monthly trends, state-wise analysis, and loan segmentation.

### 3. Details Dashboard

Contains detailed loan-level records and filtering options.

The original dataset contains 3800+ loan records.

A sample dataset has been included for demonstration purposes.

---

## Dashboard Navigation

The dashboard uses clickable navigation buttons created with Excel hyperlinks.

* Summary → Summary Dashboard
* Overview → Overview Dashboard
* Details → Detailed Dashboard

## Key Insights

* 87.5% loans are classified as Good Loans
* Fully Paid loans generate the highest returns
* Charged-Off loans have higher interest rates
* Most loans belong to 60-month terms
